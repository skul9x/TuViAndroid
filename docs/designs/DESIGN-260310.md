# 🎨 DESIGN: Sửa Bug Tên Sao Rỗng (Empty Star Name Fix)

---

## 1. Phân Tích Lỗi (Root Cause)

**Vị trí lỗi:** Cung Dậu trong chuỗi JSON sinh ra từ `GeminiClient.kt` có một object sao thừa thãi:
```json
{
  "name": "",
  "type": "sub_star"
}
```

**Nguyên nhân:** 
Trong hàm `buildPalacesJsonArray(cungList: List<CungInfo>)` của `GeminiClient.kt`, chúng ta đang iterate qua các mảng sao (`c.chinhTinh`, `fixedPhu`, `daiVanStars`, `luuStars`) và map trực tiếp qua hàm `parseStarToJson(it)`. 
Nếu trong đầu vào `cungList` (từ bước cào/parse dữ liệu trước đó) vô tình có 1 khoảng trắng `""` hoặc `"   "`, đoạn code map sẽ chạy thẳng vào hàm `parseStarToJson`. Hàm này sẽ cố trim string, trả về name là `""`, và mặc định kiểu là `sub_star`.

## 2. Giải pháp Code Chi Tiết

Thay vì thay đổi lớp Data hay Parser phức tạp, chúng ta sẽ lọc (filter) rác ngay tại khâu cuối cùng trước khi build JSON.

**File cần sửa:** `app/src/main/java/com/example/tviai/core/GeminiClient.kt`
**Hàm cần sửa:** `buildPalacesJsonArray`

**Đoạn code hiện tại:**
```kotlin
val starArr = JSONArray()
c.chinhTinh.forEach { starArr.put(parseStarToJson(it, true)) }
fixedPhu.forEach { starArr.put(parseStarToJson(it, false)) }
put("fixed_stars", starArr)

if (daiVanStars.isNotEmpty() || luuStars.isNotEmpty()) {
    val transitArr = JSONArray()
    (daiVanStars + luuStars).forEach { transitArr.put(parseStarToJson(it, false)) }
    put("transit_stars", transitArr)
}
```

**Mã thiết kế mới:**
Thêm `.filter { it.isNotBlank() }` vào trước mỗi `.forEach`.

```kotlin
val starArr = JSONArray()
c.chinhTinh.filter { it.isNotBlank() }.forEach { starArr.put(parseStarToJson(it, true)) }
fixedPhu.filter { it.isNotBlank() }.forEach { starArr.put(parseStarToJson(it, false)) }
put("fixed_stars", starArr)

val validTransits = (daiVanStars + luuStars).filter { it.isNotBlank() }
if (validTransits.isNotEmpty()) {
    val transitArr = JSONArray()
    validTransits.forEach { transitArr.put(parseStarToJson(it, false)) }
    put("transit_stars", transitArr)
}
```
